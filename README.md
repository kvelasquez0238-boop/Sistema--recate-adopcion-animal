
# UI Kit - Rescate y Adopción Animal

## Descripción
Este proyecto contiene una biblioteca de componentes visuales reutilizables para el sistema de gestión de rescates y adopciones animales.

## Archivos del proyecto
- index.html: página de demostración de los componentes.
- style.css: hoja de estilos con los diseños y colores.
- README.md: guía básica de uso.

## Componentes disponibles

### 1. Botones
- Botón primario.
- Botón secundario.
- Botón de peligro.
- Estados de interacción hover y focus.

### 2. Formularios
- Campos de texto.
- Lista desplegable.
- Efectos visuales al seleccionar los campos.

### 3. Tarjetas
- Tarjetas para mostrar información de animales rescatados.
- Bordes redondeados y sombras.

### 4. Alertas
- Urgencia alta.
- Urgencia media.
- Urgencia baja.

## Cómo utilizar el proyecto
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo index.html en un navegador.
4. Los estilos se cargarán desde style.css.

## Tecnologías utilizadas
- HTML5.
- CSS3 puro.
